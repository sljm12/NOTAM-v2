# NOTAM List Extractor

Extracts structured **Notice to Air Missions (NOTAM)** entries from raw Singapore FIR (WSSS) NOTAM list reports into clean JSON.

## Usage

```bash
python extract_notams.py <input_file> [output_file]
```

If no output file is given, output is written to `<input_stem>.json` in the same directory.

## Input format

Accepts raw text from the CAAS Singapore NOTAM List (as seen in `WSSS-NOTAM-List-06-26.md`). The script strips the preamble header, page-break footers, and parses each `+`-prefixed NOTAM entry.

## Output fields

| Field | Description |
|---|---|
| `id` | NOTAM identifier, e.g. `A1737/26` |
| `type` | Single-letter code (`N`, `R`, etc.) |
| `message` | Body text with normalised whitespace |
| `lower` | Lower altitude limit, or `null` |
| `upper` | Upper altitude limit, or `null` |
| `from` | Effective-from datetime, or `null` |
| `to` | Effective-to datetime, or `null` |
| `time_schedule` | Time schedule string, or `null` |
| `locations` | List of dicts with `latitude`/`longitude` in decimal degrees |
| `raw` | Original unmodified block text for reference |

## Example

```json
{
  "id": "A1737/26",
  "type": "N",
  "message": "PYROTECHNIC DISPLAY WILL TAKE PLACE SAFETY RADIUS 247FT CENTRED ON 011517N1034922E (WI WSAP CTR).",
  "lower": "SFC",
  "upper": "247FT AMSL",
  "from": "01 Jun 2026 00:00",
  "to": "31 Aug 2026 15:30",
  "time_schedule": "JUN 01-30 0000-1530, JUL 01-31 0000-1530, AUG 01-31 0000-1530",
  "locations": [
    { "raw": "011517N 1034922E", "latitude": 1.254722, "longitude": 103.822778 }
  ]
}
```

## Sample files

- `WSSS-NOTAM-List-06-26.md` — raw NOTAM list as distributed by CAAS
- `WSSS-NOTAM-List-06-26.json` — output generated by the script
